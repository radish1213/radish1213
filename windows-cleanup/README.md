# Windows 深度清理与优化

## 使用方法
1. 下载 `PC-Cleanup.ps1` 和 `Run-Cleanup.bat`，放在同一个文件夹（GitHub 页面右上角 Code → Download ZIP，解压）。
2. 关闭浏览器、微信、QQ 等软件。
3. 双击 `Run-Cleanup.bat`，在弹出的权限提示中点「是」。
4. 每一步都会询问 `[Y/N]`，按需选择。结束后重启电脑。

## 做了什么
| 步骤 | 内容 |
|---|---|
| 0 | 创建系统还原点（出问题可在「系统还原」中回滚） |
| 1 | 临时文件、Windows 更新缓存、错误报告、崩溃转储、缩略图缓存、回收站、浏览器缓存（不删密码和书签）、Windows.old |
| 2 | 扫描已卸载软件留下的文件夹和失效快捷方式，**由你选择**删除哪些，删除的内容先进回收站 |
| 3 | 移除资讯、天气、Cortana、纸牌、Clipchamp 等预装应用；关闭任务栏小组件 / 资讯和兴趣、开始菜单广告和 Bing 网页搜索 |
| 4 | 关闭遥测服务、高性能电源计划、关闭休眠文件、磁盘 TRIM / 碎片整理、列出开机启动项和内存占用 |
| 5 | DISM 清理旧版系统组件 |
| 6 | 桌面创建「深度清理」快捷方式并把桌面上的 Claude 快捷方式统一为 Claude 图标（需已安装 Claude 桌面版） |

## 说明
- **不清理注册表**：注册表清理几乎不提速，误删容易导致软件或系统出错。
- **「清理内存」**：Windows 会自动把空闲内存用作缓存，强制释放反而更慢。真正有效的是减少开机自启动程序和重启电脑，脚本会列出启动项和占内存最多的程序供你参考。
- 想保留某个预装应用：用记事本打开 `PC-Cleanup.ps1`，在顶部 `$BloatApps` 列表对应行首加 `#`。
